# Marvel Marathon

A cinematic Marvel marathon tracker with original poster artwork, animated graphic details, film/series filters, and persistent progress.

Posters are loaded from TMDB's public image CDN for the official production artwork. Poster availability can vary by region and network.

## Deploy to Netlify

Connect this repository to Netlify and deploy `main`. The included Netlify Function stores progress in Netlify Blobs.

For local preview:

```bash
npm install
npx netlify dev
```
